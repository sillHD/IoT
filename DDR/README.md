# DDR por laboratorio

Cada DDR sigue las diez secciones de la plantilla del curso y usa el registro
local de su práctica. Consolidación: 30 de octubre de 2026. Un DDR puede registrar
preparación pendiente; su existencia no significa que se ejecutó el laboratorio.

| Práctica | DDR | Alcance |
|---|---|---|
| Lab 0 HTTP | [DDR](../lab_http/DDR.md) | GET/POST directos y LED validados; telemetría de dashboard observada, actuación UI con salvedad. |
| Lab 0 MQTT | [DDR](../lab_mqtt/DDR.md) | Telemetría y control desde dashboard validados. |
| Lab 1 — Radio 802.15.4 | [DDR](../lab1/DDR.md) | Escaneo y medidas a 1/5/10/15 m documentados; serie detenida a 15 m. |
| Lab 2 — Malla Thread y 6LoWPAN | [DDR](../lab2/DDR.md) | Firmware y procedimiento A/B preparados; sin ejecución propia registrada. |
| Lab 3 — CoAP, CBOR y SED | [DDR](../lab3/DDR.md) | Finalizado por el equipo con evidencia medida, visual y estimada diferenciadas. |
| Lab 4 — Sensor real y frescura | [DDR](../lab4/DDR.md) | Finalizado por el equipo, con límites de referencia y sincronización explícitos. |
| Lab 5 — Border Router | [DDR](../lab5/DDR.md) | Finalizado por el equipo; dashboard móvil y 0 dBm confirmados verbalmente. |
