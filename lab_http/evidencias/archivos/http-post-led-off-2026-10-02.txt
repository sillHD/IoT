Evidencia de POST /api/control para apagar el LED WS2812
Fecha: 2026-10-02
Placa: ESP32-C6

Comando ejecutado desde WSL:
curl -i --max-time 5 -X POST http://192.168.1.9/api/control \
  -H 'Content-Type: application/json' \
  -d '{"state": 0}'

Respuesta observada:
HTTP/1.1 200
Transfer-Encoding: chunked
Content-Type: application/json

{"status": "ok"}

Confirmacion serial observada:
[00:17:03.554,000] <inf> lab0_http: Actuating command received, LED state: 0

La respuesta HTTP y la consola serial confirman que el servidor acepto el
comando y que la aplicacion aplico el estado 0 al LED.
